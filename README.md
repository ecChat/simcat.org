# SimCat

SimCat 官方发布仓库 / Official release repository for SimCat.

- Website 官网: https://www.simcat.org
- Docs 文档: https://documents.simcat.org

预编译产物按版本存放在 `releases/<version>/` 目录，并通过 [Releases](https://github.com/ecChat/simcat.org/releases) 页面发布，附带 `.sha256` 校验文件。

Prebuilt packages for all supported platforms (iOS, Android, macOS, Windows, Linux, OpenWrt) are published on the [Releases](https://github.com/ecChat/simcat.org/releases) page with SHA-256 checksums.
